# Holly HTML

> The only HTML notes you need.

Holly HTML is a collection of essential HTML concepts, examples, and references, organized in one place.

The notes are written to be **beginner-friendly**, so you can start from the basics and build your understanding step by step. They are also structured with **interview preparation in mind**, covering the concepts and questions commonly expected from someone with a good understanding of HTML.
